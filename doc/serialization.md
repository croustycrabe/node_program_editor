# Serialization: design and logic files

A graph is saved as **two JSON documents** joined by node and edge ids:

| | Logic file | Design file |
|---|---|---|
| Purpose | what the program does | how it looks |
| Consumer | your execution engine, your backend, version control | the editor |
| Content | node types, parameters, ports, links, functions, your `data` | positions, sizes, locks, styles, edge styles / labels / waypoints, viewport, grid |
| Class | `LogicDocument` | `DesignDocument` |

```dart
final logic = controller.exportLogic(metadata: {'name': 'Line 3 inspection'});
final design = controller.exportDesign();
final logicJson = logic.toJsonString();          // pretty printed
final designJson = design.toJsonString(pretty: false);

controller.load(LogicDocument.fromJsonString(logicJson),
    DesignDocument.fromJsonString(designJson));
controller.load(LogicDocument.fromJsonString(logicJson));  // auto layout
```

Loading without a design file (for example a logic file generated by a
backend) lays the nodes out in layers from left to right. Nodes missing from a
design file are laid out below the others.

## Logic file

```json
{
  "format": "node_program_editor/logic",
  "schemaVersion": 1,
  "metadata": {"name": "Line 3 inspection"},
  "nodes": [
    {
      "id": "nk3f9a00010x1z",
      "type": "vis.threshold",
      "title": "Find parts",
      "params": {"range": [110.0, 255.0], "invert": false},
      "inputs": [{"id": "in", "type": "image", "maxLinks": 1}],
      "outputs": [{"id": "out", "type": "image"}],
      "data": {"owner": "qa"}
    },
    {
      "id": "nk3f9a00020a4b",
      "type": "super:snk3f9b0003c9d",
      "params": {"sigma": 2.5},
      "inputs": [{"id": "in1", "label": "image", "type": "image", "maxLinks": 1}],
      "outputs": [{"id": "out1", "label": "mask", "type": "image"}]
    }
  ],
  "edges": [
    {
      "id": "ek3f9a0004b7c1",
      "source": {"node": "nk3f9a00010x1z", "port": "out"},
      "target": {"node": "nk3f9a00020a4b", "port": "in1"}
    }
  ],
  "superNodes": {
    "snk3f9b0003c9d": {
      "id": "snk3f9b0003c9d",
      "name": "Denoise",
      "category": "Functions",
      "inputProxy": "n…", "outputProxy": "n…",
      "inputs": [...], "outputs": [...],
      "params": [{"name": "sigma", "label": "Blur sigma", "node": "n…", "param": "sigma"}],
      "nodes": [...], "edges": [...]
    }
  }
}
```

- `params` hold values encoded by their `ParamType` (`Quantity` →
  `{"value", "unit"}`, `RangeValue` → `[start, end]`, `Matrix` →
  `{"rows", "cols", "data"}`, colors → `"#AARRGGBB"`, images →
  `{"bytes": base64 | "uri"}`, `DateTime` → ISO-8601...).
- `inputs` / `outputs` summarize the ports so an engine can work without the
  registry. Instance-specific ports are fully described in `customPorts`.
- `data` is your node payload (`NodeInstance.data`); runtime state is never
  saved.
- `metadata` is free-form.

## Design file

```json
{
  "format": "node_program_editor/design",
  "schemaVersion": 1,
  "viewport": {"x": 120.0, "y": 80.0, "zoom": 0.8},
  "canvas": {"gridStyle": "dots", "gridSpacing": 20.0, "majorEvery": 5, "snapToGrid": true,
             "snapEdgesToGrid": false, "defaultEdgeStyle": {"pathType": "smoothStep"}},
  "nodes": {
    "nk3f9a00010x1z": {"x": 300.0, "y": 40.0, "w": 220.0, "h": 220.0, "locked": true,
                        "style": {"headerColor": "#FF9333EA"}}
  },
  "edges": {
    "ek3f9a0004b7c1": {"style": {"pathType": "orthogonal", "endMarker": "arrowClosed",
                                  "dashPattern": [8.0, 6.0]},
                        "label": "mask", "waypoints": [[640.0, 120.0]]}
  },
  "superNodes": {"snk3f9b0003c9d": {"nodes": {...}, "edges": {...}}}
}
```

## Robustness

- Every `fromJson` is lenient: ints or doubles, missing optional keys, unknown
  keys are fine.
- **Unknown node types** load as `UnknownNodeDefinition` placeholders with the
  ports listed in the logic file, so links survive and re-saving writes the
  same data back.
- Links to missing nodes or ports are dropped.
- Invalid parameter values fall back to the type default
  (`ParamType.decodeAny` never throws).
- `schemaVersion` is written so future versions can migrate old files.

## Fragments (clipboard)

`GraphFragment` (`"format": "node_program_editor/fragment"`) bundles a subset
of nodes and links with their design and the functions they use. It is what
copy / paste puts on the system clipboard; you can also use it for templates:

```dart
final template = GraphFragment.capture(controller.graph, selectedIds).toJsonString();
controller.pasteFragment(GraphFragment.tryParse(template)!, at: dropPoint);
```

## Lower level

`GraphCodec.encode(nodes, edges)` / `GraphCodec.decode(...)` convert between a
`Graph` and the document parts; `GraphCodec.autoLayout(graph)` is the layered
layout used on import.
